# Аудит системы — 2026-08-31

Состояние «до». Машина: MacBook Air (M4, 10 ядер), 16 ГБ RAM, SSD 460 ГБ,
macOS 27.0 beta. Аптайм на момент аудита — почти 6 суток.

## Главные проблемы

### 1. Память: своп забит (5.7 из 6 ГБ)

При 16 ГБ RAM постоянно висели **пять** серверов данных:

- MySQL, PostgreSQL 14, RabbitMQ, Redis — автозапуск через `brew services`;
- MongoDB 5.0 — **x86_64-сборка через Rosetta 2** с `KeepAlive` (LaunchAgent).

Ресёрч показал: живых клиентских подключений — ноль; очереди RabbitMQ пусты;
у Redis не нашлось потребителей в коде проектов; Redis-дамп не обновлялся с 2022.

### 2. Ночной чистильщик молча сломан больше года

Root-демон `com.user.cleaner` ежедневно в 05:00 запускал скрипт по абсолютному
пути, но папка проекта переехала — в логе сплошные «No such file or directory».
В самом скрипте нашёлся баг: `rm -rf ".../{Cache,Code Cache}"` — brace expansion
внутри кавычек не работает, строки-нооп.

**Мораль**: демоны с абсолютными путями к домашним папкам ломаются молча;
логи `launchd` никто не читает.

### 4. Диск (291/460 ГБ занято)

Крупное и лишнее: видео-обои 3.7 ГБ; кэши Playwright 554 МБ, Yarn 499 МБ,
`~/.cache` 937 МБ; остатки удалённого Яндекс.Браузера 554 МБ; огрызок
Photoshop 2025 (36 МБ рядом с полноценным 2026); 79 устаревших brew-формул.
Папка Claude (11 ГБ) оказалась почти вся легитимной: 8.6 ГБ — один живой
VM-образ для локальных агентских сессий, трогать нельзя.

### 5. Загадка двух блогов (решена)

В PostgreSQL жила база `thehubblog` — **пустой** каркас блога на Strapi v3
(0 статей). Актуальный блог оказался в MySQL: Strapi v5, отдельный проект.
Прод деплоится на удалённый сервер (pm2), локальная MySQL-база — только для
разработки. Старый каркас удалён после дампа.

## Здоровое (не трогали)

FileVault включён, SIP включён, Gatekeeper включён, батарея — 83 цикла / 100%
ёмкости. Karabiner, AdGuard, Amphetamine, StreamDock, LocalSend, OrbStack,

## Хронология применения

1. Дампы `phantom` и `thehubblog` → локальный бэкап (вне git).
2. `brew services stop` mysql/redis/rabbitmq; `brew pin mysql`; `brew upgrade` + `cleanup`.
3. janitor v2 установлен (см. репозиторий macos_janitor).
4. `cleanup_user.sh` — пользовательские удаления.
5. `sudo cleanup_root.sh` — демоны и приложения.
6. Перезагрузка, контрольный `audit.sh`.
